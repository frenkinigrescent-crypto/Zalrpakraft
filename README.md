# Zalepacraft

(внутренний ID мода — `zalrpakraft`, папки конфигов называются так же)

Связующий мод сборки (Minecraft 1.21.1, NeoForge).

## Что уже есть (часть 1–2)
- **Пробуждение.** При первом входе: темнота, сердцебиение, веки моргают, взгляд с неба опускается вперёд. В руке появляется *Дневник незнакомца*, справа сверху — задание.
- **Дневник** с координатами домика незнакомца. Домик строится автоматически в 90–160 блоках от спавна.
- **Звёздный стол** в домике (неразрушаемый). ПКМ открывает звёздную карту: галактики = группы модов, планеты = моды, метеоры = боссы, врата = измерения.
- **Задания** в правом верхнем углу ведут по карте.
- **Ключи.** Ад и Рай (Paradise Lost) закрыты, пока игрок не применит ключ (ПКМ, один раз навсегда для себя).
- **12 глаз.** Обычное око Эндера в рамку не вставляется. Каждый из 12 глаз — один раз на портал.
- **Боссы** усилены (здоровье ×3, урон ×1,5, +25% здоровья за каждого игрока рядом сверх первого). Трофей падает каждому игроку рядом.

## Достижения (0.2.0)
23 достижения в своей вкладке: от «Пробуждения» до «Конца пути», плюс по одному на каждую галактику и «Не ходи один» (метеор вчетвером). Вместо стандартного тоста — светящаяся плашка по центру сверху: фиолетовая (достижение), бирюзовая (цель), золотая с искрами (испытание).

## Главное меню и иконка (0.2.0)
Своё меню: живое звёздное небо с туманностями и метеорами, кольцо из 12 глаз, логотип с бликом, фразы дня, стилизованные кнопки. Своя иконка окна («звёздный глаз»). Отключается в `config/zalrpakraft-client.toml`.

## Звёздная карта с клавиатуры (0.3.4)
После первого касания Звёздного стола карта открывается где угодно клавишей **K** (меняется в Настройки → Управление → Zalepacraft). Задание «Небо в кармане» в Прологе учит этому и показывает назначенную клавишу.

## Книга заданий (0.3.0)
Клавиша **J** (или кнопка на звёздной карте). 10 глав, 76 заданий: Пролог, Колыбель, Шестерня, Ток, Небосвод, Арсенал, Тайна, Угроза, Метеоры, Двенадцать глаз. Задачи: добыть предметы, победить мобов, изучить узел карты, сюжетные шаги. Награды — предметы и опыт, забираются кнопкой в книге. Любое задание можно «отслеживать» — оно появится в панели справа сверху со счётчиком. Задания с предметами или мобами, которых нет в сборке, скрываются сами (список — в логе).

## Настройка без пересборки
Файлы в `config/zalrpakraft/` имеют поле `_version`. Если в новой версии мода файл обновился, старый заменяется автоматически, а прежний сохраняется рядом как `.bak`.

- `config/zalrpakraft-common.toml` — множители боссов, замки измерений, интро.
- `config/zalrpakraft/bosses.json` — ID боссов → трофей → метеор на карте. При запуске мод пишет в лог, каких ID нет в сборке (`Zalepacraft: босс … не найден`).
- `config/zalrpakraft/quests.json` — все задания, награды и связи между ними.
- `config/zalrpakraft/progression.json` — вся звёздная карта: узлы, координаты, условия, подсказки.

## Сборка
GitHub Actions собирает jar и запускает сервер-самотест (домик построен, стол на месте, карта без битых связей). Готовый файл — в артефакте `zalrpakraft`.
